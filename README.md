# InAmigos Foundation — NGO Awareness Webpage

## Files
- `index.html` — complete webpage
- `style.css` — responsive styling
- `assets/` — reserved for approved NGO images if you want to add them

## How to run
Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Before submission
1. Replace the four gallery visual panels with approved photographs from InAmigos Foundation's official website/social media, if permitted.
2. Check all links.
3. Test desktop and mobile layouts.
4. Take screenshots.
5. Upload the whole folder to Google Drive.
6. Host with GitHub Pages or Netlify and submit the live URL.
